# Mini Task Manager (FER202 - Slot 7)

React + Vite. Dùng `useState`, `useEffect`, `useContext` (ThemeContext) và custom hook `useLocalStorage`.

## Chạy

```bash
npm install
npm run dev
```

## Chức năng

- Thêm công việc, đánh dấu hoàn thành, xoá
- Lọc: Tất cả / Chưa làm / Hoàn thành + tìm kiếm theo tên
- Thống kê: Tổng | Chưa làm | Hoàn thành
- Chuyển theme sáng / tối (Context)
- Dữ liệu và theme lưu vào localStorage (F5 vẫn còn)
